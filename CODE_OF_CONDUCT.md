# Code of Conduct

GitHub CLI Extension Atlas is a curated technical resource. The project works best when corrections, suggestions, and disagreements stay factual, specific, and respectful.

## Expected behavior

- Keep feedback focused on extension metadata, installability, maintenance status, categories, comparisons, or documentation clarity.
- Assume good intent when someone reports a correction or asks why an extension is included.
- Be specific when suggesting a change: name the repository, field, link, or guide section that should change.
- Respect maintainers' time. Do not use this project to pressure extension authors for stars, promotion, endorsements, or replies.

## Unacceptable behavior

- Harassment, threats, personal attacks, or discriminatory language.
- Spam, paid placement, undisclosed promotion, or repeated low-signal suggestions.
- Publishing private information or credentials.
- Misrepresenting this atlas as an official GitHub project or as an endorsement from listed extension maintainers.

## Reporting

Use GitHub issues for concrete catalog corrections and Discussions for questions or rough ideas. If a conduct issue appears in a public thread, open a maintainer-facing issue with links and a short summary.

Maintainers may edit or remove comments, close threads, block accounts, or pause discussion when behavior makes the resource less useful or less safe for contributors.
