# gh-extension-atlas v0.2.22

This patch release adds a browser-based installed extension audit page.

## What changed

- Added [`audit.html`](https://sjh9714.github.io/gh-extension-atlas/audit.html) for pasting `gh extension list` output.
- The page compares pasted extensions with the reviewed atlas catalog locally in the browser.
- Shows installed entries already reviewed by the atlas.
- Shows installed extensions that are not listed yet.
- Shows missing Top Picks and workflow recommendation coverage.
- Adds a copyable install-command block for missing Top Picks.
- Links the audit page from the README, catalog, chooser, compare page, API manifest, health snapshot, and sitemap.

## Try it

Open the browser audit page:

```text
https://sjh9714.github.io/gh-extension-atlas/audit.html
```

Then paste output from:

```sh
gh extension list
```

For the local CLI equivalent:

```sh
gh extension list | npm --silent run catalog:audit-installed -- --stdin
```

## Validation

- `npm test`
