# gh-extension-atlas v0.2.19

This patch release collects trust, feedback, and discovery improvements made after the starter-pack JSON release.

## Added

- `CODE_OF_CONDUCT.md` with factual, respectful contribution expectations.
- `SECURITY.md` with catalog security scope, install bundle safety notes, and reporting paths.
- `docs/faq.md` for official-status, curation, freshness, install bundle, correction, and star-discovery questions.
- `docs/maintainer-badges.md` with optional badge guidance for extension maintainers.
- A site/API/install bundle feedback issue form.

## Improved

- GitHub Pages entry points now expose FAQ and GitHub repository CTAs more clearly.
- README feedback and maintainer sections now link to security, FAQ, issue forms, and optional badge guidance.
- API manifest, health snapshot, and LLM context files now include the FAQ entry point.

## Quick Checks

Open the FAQ:

```sh
curl -fsSL https://sjh9714.github.io/gh-extension-atlas/faq.md
```

Check the API manifest FAQ endpoint:

```sh
curl -fsSL https://sjh9714.github.io/gh-extension-atlas/api/index.json \
  | jq '.endpoints.faq'
```

Open maintainer badge guidance:

```sh
curl -fsSL https://sjh9714.github.io/gh-extension-atlas/maintainer-badges.md
```
