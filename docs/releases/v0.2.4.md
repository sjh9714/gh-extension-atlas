# gh-extension-atlas v0.2.4

This patch release adds a repository search workflow guide and a generated search starter pack.

## Added

- GitHub Repository Search CLI Extension Guide:
  https://sjh9714.github.io/gh-extension-atlas/guides/repository-search-extensions.html
- Search And Discovery starter pack:
  https://sjh9714.github.io/gh-extension-atlas/install/starter-packs/search-and-discovery.txt

## Improved

- Search category page now links to its workflow guide.
- README Workflow Guides now includes repository search as a first-class entry point.
- Search starter pack now favors active repository/code search tools over stale starred-repository browsing.

## Quick Checks

Open the repository search guide:

```sh
curl -fsSL https://sjh9714.github.io/gh-extension-atlas/guides/repository-search-extensions.html
```

Review the search starter pack:

```sh
curl -fsSL https://sjh9714.github.io/gh-extension-atlas/install/starter-packs/search-and-discovery.txt
```

The guide separates repository search, code search, starred-repository search, and local clone workflows so readers can pick the smallest useful extension first.
