# gh-extension-atlas v0.2.20

This patch release turns recent catalog work into more practical entry points for choosing and comparing GitHub CLI extensions.

## Added

- Browser-friendly [Workflow Recommendations](https://sjh9714.github.io/gh-extension-atlas/recommendations.html) with install commands, avoid-if notes, status labels, and detail links.
- Public workflow recommendation API and schema:
  - `https://sjh9714.github.io/gh-extension-atlas/api/recommendations.json`
  - `https://sjh9714.github.io/gh-extension-atlas/api/recommendations.schema.json`
- Browser-friendly [Install Bundle Index](https://sjh9714.github.io/gh-extension-atlas/install/) for Top Picks, workflow starter packs, category bundles, and the full catalog.
- Local comparison helper:

```sh
npm --silent run catalog:compare -- gh-dash gh-notify gh-pr-review
```

## Improved

- Searchable Pages entry points now expose schema.org structured data for catalog, chooser, workflow recommendations, install bundles, and extension detail pages.
- `npm test` now checks generated structured data and the new local comparison helper.
- README and data recipes now show how to compare overlapping extension choices before installing.

## Quick Checks

Open workflow recommendations:

```sh
curl -fsSL https://sjh9714.github.io/gh-extension-atlas/recommendations.html
```

Open install bundles:

```sh
curl -fsSL https://sjh9714.github.io/gh-extension-atlas/install/
```

Compare local catalog entries:

```sh
npm --silent run catalog:compare -- dlvhdr/gh-enhance fchimpan/gh-workflow-stats
```

Check the manifest entry for install bundles:

```sh
curl -fsSL https://sjh9714.github.io/gh-extension-atlas/api/index.json \
  | jq '.endpoints.install_bundles'
```
