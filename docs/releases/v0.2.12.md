Open the awesome overview:

```sh
curl -fsSL https://sjh9714.github.io/gh-extension-atlas/awesome-github-cli-extensions.html
```

```sh
curl -fsSL https://sjh9714.github.io/gh-extension-atlas/sitemap.xml \

```
