# gh-extension-atlas v0.2.23

This patch release prepares the browser audit flow for a follower-independent Show HN launch.

## What changed

- Opens the Show HN link on [`audit.html?demo=1`](https://sjh9714.github.io/gh-extension-atlas/audit.html?demo=1), so first-time visitors see a sample audit result immediately.
- Adds a visible 15-second audit flow: copy `gh extension list`, paste the output, and review workflow gaps.
- Adds privacy and trust notes to the audit page: no sign-in, no tracking, and no upload.
- Adds clipboard paste support with a manual-paste fallback when browser permissions block clipboard reads.
- Adds copy actions for the audit command, missing Top Picks installs, workflow gap installs, and audit summary.
- Adds a restrained README support note while keeping factual corrections and missing-extension suggestions as the primary support path.
- Adds guarded Show HN launch helpers for preflight, second-wave review recording, story recording, response monitoring, human-written comment notes, and 24-hour review.

## Try it

Open the sample audit:

```text
https://sjh9714.github.io/gh-extension-atlas/audit.html?demo=1
```

Then replace the sample with your own installed extensions:

```sh
gh extension list
```

## Launch helpers

Run the final readiness check after the maintainer guardrail expires:

```sh
npm run launch:show-hn:ready
```

After the Hacker News item exists:

```sh
npm run launch:show-hn:record-share -- --story STORY_URL
npm run launch:show-hn:monitor -- --story STORY_URL
```

After 24 hours:

```sh
npm run launch:show-hn:review-24h -- --story STORY_URL --post
```
