# gh-extension-atlas v0.2.3

This patch release adds workflow-specific guide landing pages that are easier to share than the full catalog.

## Added

- GitHub Actions CLI extension guide:
  https://sjh9714.github.io/gh-extension-atlas/guides/github-actions-extensions.html
- Git branch cleanup CLI extension guide:
  https://sjh9714.github.io/gh-extension-atlas/guides/branch-cleanup-extensions.html
- GitHub notification triage CLI extension guide:
  https://sjh9714.github.io/gh-extension-atlas/guides/notification-triage-extensions.html

## Improved

- README now links workflow guides as first-class entry points.
- Category pages link to their matching workflow guide when one exists.
- Sitemap includes workflow guide landing pages for better discovery.
- Site generation now supports multiple workflow guide pages from one reusable template.
