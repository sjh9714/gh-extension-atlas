# gh-extension-atlas v0.2.21

This patch release adds a local audit helper for comparing installed GitHub CLI extensions against the reviewed atlas catalog.

## What changed

- Added `catalog:audit-installed` for auditing `gh extension list` output.
- Reports installed extensions that are already reviewed in the atlas.
- Reports installed extensions that are not listed in the atlas yet.
- Reports missing Top Picks and workflow recommendation coverage.
- Added demo, JSON, and install-command output modes for automation and validation.
- Documented the helper in the README and data recipes.

## Try it

Audit extensions installed in the current GitHub CLI environment:

```sh
npm --silent run catalog:audit-installed
```

Pipe saved or live `gh extension list` output:

```sh
gh extension list | npm --silent run catalog:audit-installed -- --stdin
```

Print install commands for missing Top Picks from a demo list:

```sh
npm --silent run catalog:audit-installed -- --demo --format install
```
