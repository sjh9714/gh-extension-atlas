# Markdown Preview Extensions

Markdown preview tools are most useful before publishing README changes, issue templates, release notes, and docs.

| Extension                                                              | Pick it when                                                     | Tradeoff                                                    |
| ---------------------------------------------------------------------- | ---------------------------------------------------------------- | ----------------------------------------------------------- |
| [gh-markdown-preview](https://github.com/yusukebe/gh-markdown-preview) | You want a popular GitHub-style preview flow.                    | Less focused on offline use.                                |
| [gh-gfm-preview](https://github.com/thiagokokada/gh-gfm-preview)       | You want standalone or offline GitHub-flavored Markdown preview. | Smaller project than gh-markdown-preview.                   |
| [gh-slack](https://github.com/rneatherway/gh-slack)                    | You are archiving Slack conversations as Markdown.               | It solves a different problem than previewing project docs. |

## Recommendation

Start with [gh-markdown-preview](https://github.com/yusukebe/gh-markdown-preview) for GitHub-like rendering. Use [gh-gfm-preview](https://github.com/thiagokokada/gh-gfm-preview) if offline preview is important.
