Use The Workflow You Have Right Now

Install one extension for the job in front of you, try it on a real repository, then come back only if you need a narrower alternative.

If Two Choices Look Similar

  • Choose gh-pr-review over gh-dash if inline PR review comments are the main job.
  • Choose gh-workflow-stats over gh-enhance if you want CI metrics rather than an Actions TUI.
  • Choose gh-notify over gh-dash if notifications are the only queue you care about.

When To Avoid Installing

  • The built-in gh command already solves the job.
  • You only need the command once.
  • The extension is archived, poorly documented, or asks for permissions you do not understand.

Safer Install Flow

gh extension install OWNER/REPO
gh extension list
gh extension remove EXTENSION_NAME
