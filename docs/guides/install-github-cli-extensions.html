A practical setup guide for installing, listing, updating, auditing, pinning, and removing GitHub CLI extensions.

GitHub CLI extensions are not verified, signed, or endorsed by GitHub. When you install or upgrade an extension, you are trusting its publisher.

Before You Install

  • Check that the repository is not archived.
  • Read the README and confirm what the extension does.
  • Make sure the install command uses the expected OWNER/REPO path.
  • Review maintenance status before using an extension for repeated work.

Install

gh extension install dlvhdr/gh-dash

Use OWNER/REPO format for GitHub-hosted extensions.

List

gh extension list

Use this output with the atlas audit page to see reviewed and missing tools.

Dry-Run Updates

gh extension upgrade --all --dry-run

Check what would update before upgrading everything.

Remove

gh extension remove gh-dash
gh extension list

Remove tools that you tried once and no longer use.

Audit Installed Extensions

Paste gh extension list output into the browser audit page, or run the local audit script from a clone of the atlas.

gh extension list | npm --silent run catalog:audit-installed -- --stdin
Open browser audit Read the audit guide

Pin A Version

gh extension install OWNER/REPO --pin v1.2.3

Pinned installs are useful for reproducible team setup, but you still need to decide when to upgrade.
